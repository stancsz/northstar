# Install

Copy this repository directory into your local skills directory with the folder name `q4-collaboration-protocol`.

PowerShell:

```powershell
Copy-Item -Recurse -Force . "$env:USERPROFILE\.agents\skills\q4-collaboration-protocol"
```

Repository-local installation is also supported by copying it into `.agents/skills/q4-collaboration-protocol/`. Invoke it as `$q4-collaboration-protocol`, then give it a goal, project, or task to classify.
