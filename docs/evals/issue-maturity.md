## Repair and learning

Case 7 exposed a real instruction-interpretation gap: shared review context allowed one independent artifact's blockers to suppress another's verdict, and a failing implementation contaminated spec readiness. The [checklist](../../skills/codex-qa/references/spec-review.md) now explicitly gates each spec separately and names separate spec/implementation verdicts. Its initial failure remains in this case's denominator; a same-context successful recheck cannot prove cold-run reliability of the repair.

The primary then repaired the seeded custom spec and notes function, preserving originals: removed sensitive examples/self-acceptance, replaced toast criteria with separate-process readback and blank-input invariants, resolved the blocking question, wrote actual file contents and rejected blanks with a message. The independent same-context targeted recheck passed all three spec passes for both profiles. A separate Python process read back `hello`; empty and whitespace-only attempts returned `validation_error` with a nonempty message and preserved `hello`. The supplied function/file contract is READY; missing app/UI integration remains UNVERIFIED and is outside the fixture contract. These fixture repairs are disposable test work, not a new application shipped in the skill bundle.

One fixture-side scope error was contained: after persistence was implemented, running the unchanged happy check from the repository root briefly created an owned `notes.txt` containing `hello`. The reviewer removed that generated file, disclosed the mistake and confirmed it no longer exists. Release QA uses owned scratch as the working directory. This side effect is retained as an execution limitation; a repaired fixture is not a flawless first-pass result.

Reusable lesson: evaluate each artifact and each acceptance scope explicitly; test resulting data rather than status text, and run relative-path probes inside owned scratch. The independent fixture recheck executed the chosen correction. Apply those lessons to the staged-release review before publication; do not reopen the passing fixtures without changed evidence.
