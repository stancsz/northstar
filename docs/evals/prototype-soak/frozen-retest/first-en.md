# ToolHarbor
## Keep community tool loans moving

For Cedar Makerspace coordinators: make each school handoff easier to see, prepare, and confirm.

*Fictional concept • First-draft screens; not a working service*

![ToolHarbor loan overview screen — illustrative placeholder](images/toolharbor-overview.png)

---

# One request, many loose ends

Cedar Makerspace coordinates school borrowing across messages, lists, and staff shifts. A request can be hard to track when kit counts, pickup plans, and return details live in different places.

ToolHarbor proposes one shared loan view: what was requested, what needs checking, and what is ready for handoff.

![ToolHarbor request queue screen — illustrative placeholder](images/toolharbor-requests.png)

---

# One loan, clearly counted

Oak School requests **8 drill kits** and **12 safety sets** for **20 participants** on **2026-11-12**. Pickup is **09:00**; return is **16:00**.

The coordinator reviews the request in one place, confirms the counts and time window, then prepares the loan record for staff review.

![ToolHarbor loan details screen — illustrative placeholder](images/toolharbor-loan-details.png)

---

# Check before the handoff

Jamie Lee checks the Bench Room pickup plan against the prepared loan: items, quantities, pickup at 09:00, and return at 16:00.

Staff confirm what is ready and resolve any mismatch before handing items over. This concept supports coordination; it does not guarantee safe use or replace staff judgment.

![ToolHarbor staff handoff screen — illustrative placeholder](images/toolharbor-handoff.png)

---

# A clearer workspace for Cedar

Cedar Makerspace gets a proposed shared workspace for requests, loan details, and handoff checks. Staff can see the same loan plan as it moves toward pickup and return.

Oak School borrows through the coordinated loan; there is **no paid add-on for the school** in this concept. The workflow is proposed, not validated with users.

![ToolHarbor workspace screen — illustrative placeholder](images/toolharbor-workspace.png)
