# 现场人手，可按需另购

## 主办方选择是否加购有人值守的送达

对河岸市集，主办方可单独购买**工作人员送达并现场交接**；也可沿用自己的取货或运输安排。此项不是工作台订阅的必选部分。

- 租赁团队：备货、确认租赁清单
- 可选交付人员：按约定送达、与主办方现场点交
- 主办方：确认收到；异常当场记录并联系租赁团队

**服务范围、价格和可用时段均待验证；不承诺准时或零差错。**

# 先看你现在怎么做

## 再判断 StageKit 值不值得试

1. 你现在用什么工具管理租赁清单、变更和交接？最麻烦的一步是什么？
2. 谁会使用这份工作台？谁负责打包、送达和确认？缺少什么才会让你不用？
3. 如果这套工作台适合你的租赁业务，你觉得每个经营地点每月值多少？请先说一个金额和币种，**也可以是 0**。

**先听你的未提示估价，再讨论任何价格范围。**假设答案不是购买承诺。
