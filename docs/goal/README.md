# Goals

Each supervisor owns its `docs/goal/<goal>/GOAL.md` and index entry. Read the orchestrator's direction, assign bounded tasks and report paths, inspect worker reports and artifacts, and record task decisions and the orchestrator's final goal decision. Coordinate shared index edits through one assigned editor during concurrent work. Link [worker reports](../reports/README.md) and evaluation results rather than duplicating them.
