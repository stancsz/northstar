# Implementation report: dispatch context

Status: documentation change accepted with limited replicated Claude Code CLI evidence; broad effect remains unproven. Owner: primary agent.

Changed `skills/codex-subagents/SKILL.md` and its orchestrator/supervisor templates to put the assigned result and immediate next action first; state essential facts, acceptance criteria and scope/authority constraints in the brief; link only supporting background; name consequential unknowns; and use a one-sentence understanding check only for substantial or ambiguous assignments. Existing five brief elements and authority/accountability rules remain.

The initial Codex Advisor council favored refining existing assignment briefs with essential facts versus linked background and a next action, plus a conditional understanding check. It rejected arbitrary length caps and mandatory acknowledgment turns. An independent scenario review found no material defect. After the first native trials, Sol recommended keeping pass criteria and authority limits explicit in the prompt and running a neutral missing-input pair; both were incorporated. After the CLI trials, the council recommended one matched Claude CLI replication and conditional commit based on the result. That replication repeated the treatment completion advantage over control. Council usage for the final review: Gemini 1,591 tokens and GPT-6.1 Sol 853 tokens; its advice changed the verification action (`decision_changed: true`). The earlier advice receipts and usage are retained in the task transcript.

The [evaluation](../../evals/dispatch-context.md) and [CLI trial report](cli-trials.md) record three matched native pairs, two exploratory/matched Claude CLI pairs, and Codex CLI smoke and task runs. The Claude replication used identical fixture-file hashes, the localhost:4000 route, model alias `default`, read-only tools and low effort. Its acceptance was a three-line text response, not file creation. Treatment returned the correct summary; control reached its turn limit without a handoff after an extra directory read. Both Codex CLI task briefs drifted into tool-wrapper troubleshooting, with different low-level errors, so that client gives no comparative evidence. Native trials had no direct token/time measurements. Do not claim broad drift prevention or measured savings.

The independent reviewer has the original scenario review and a follow-up review of the CLI evidence in [review.md](review.md). The review and evaluation retain causal limitations and the unresolved Codex CLI behavior.
